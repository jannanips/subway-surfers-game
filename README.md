# Subway Suffer

A simple browser game inspired by Subway Surfers. You dodge obstacles, jump barriers, slide under signs, and collect coins.

## Run it locally

1. Open a terminal in this folder.
2. Start a local web server:

```bash
python3 -m http.server 8000
```

3. Open `http://localhost:8000` in your browser.

## Controls

- Left / Right arrow keys or on-screen buttons: move between lanes
- Up arrow / W / Space: jump
- Down arrow / S: slide

## Files

- `index.html` — page layout
- `style.css` — game styling
- `game.js` — game logic and rendering

Enjoy the run!
